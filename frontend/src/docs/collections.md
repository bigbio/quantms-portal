# Collections

A **collection** is a curated grouping of datasets that belong together — for
example, datasets sharing a scientific theme or analysis type. Collections give the
corpus structure: instead of one flat list of datasets, related studies are grouped
so you can browse and compare them meaningfully.

## What a collection is

- A **named, curated set of datasets** with a shared purpose.
- Backed by aggregate information — how many datasets it contains and summary
  counts across them — so you can size it up at a glance.
- A stable entry point you can link to and return to.

Collections are curated: a dataset is placed into a collection deliberately, so the
grouping reflects an editorial decision, not an automatic category.

## How collections relate to datasets

- A collection **contains** datasets.
- A dataset can belong to a collection (and, where relevant, appear in more than
  one), so collection membership is part of a dataset's identity in the portal.
- Filtering and faceting in [Dataset Search](/apps/dataset-search) let you narrow
  by collection, and [Peptide & Protein Search](/apps/peptide-search) lets you
  restrict a biological query to a collection.

## How to browse them

- Start from the **[Collections](/collections)** page to see every collection with
  its counts.
- Open a collection to browse the datasets inside it.
- Open any dataset for its metadata and file links (see
  [Download data](/docs/download)).

Corpus-wide, per-collection statistics are summarized on the
[Statistics](/statistics) page.
